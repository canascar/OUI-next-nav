Anatomy — Zone Layout
The bar is divided into 3 logical zones separated by visual dividers. Zone 2 (canvas) only appears when the canvas panel is open.
Zone 1 Title | Share ⋯
Zone 2 Tab1 Tab2 Tab3 | + ☰
Zone 3 Views ▦ N
Zone 1 (Chat): Title (truncates with ellipsis) + Share button + Session menu (⋯)
Zone 2 (Canvas): Tab pills (overflow hidden, scroll) + Add tab (+) + Tab list (☰) — hidden when canvas collapsed
Zone 3 (Views): Panel icon + count pill — toggles canvas open/closed. Active state when panel is visible.
Behavior Rules
Title lifecycle:
1. Home state → Zone 1 shows env context (muted, light weight)
2. First user message sent → Zone 1 stays as env context
3. AI responds → Title generates with shimmer animation, replaces env context
4. Title settles → Static, truncated with ellipsis if too long

Canvas panel toggle:
• Panel open → Zones 1 + 2 + 3 all visible. Views pill shows "active" state.
• Panel closed → Zone 2 disappears entirely. Zone 1 gets more room. Views pill is "inactive" (border only).

Session actions:
• Only appear once a conversation has started (title exists)
• Share button: opens share dialog
• Menu (⋯): rename, duplicate, delete, export

Tab overflow:
• Tabs beyond available width are hidden behind the Tab List button (☰)
• Tab List button shows a dropdown with all tabs for switching
• Active tab is always visible (scroll into view)
