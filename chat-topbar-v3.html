Layout Spec
Single line, 3 logical zones:

[Title] [Share] [Manage] ··· spacer ··· | [Tab1] [Tab2] [+] [☰] | [▦ Panel]

The single panel button (▦):
• Always present, always rightmost
• Inactive (gray) = canvas panel is closed
• Active (accent bg) = canvas panel is open
• Clicking it toggles the canvas panel open/closed

When panel is closed:
• Tab group + dividers hidden
• Bar simplifies to: [Title] [Share] [Manage] ··· spacer ··· [▦]

When panel is open:
• Tabs slide in between the spacer and the panel button
• Dividers bracket the tab group
• Tab list (☰) only shows when there are 3+ tabs
